Keys are session-only
No API key is stored in the website repository. The key stays in memory until this tab is refreshed or closed.
Security: this is a static GitHub Pages app. Browser-based API calls expose the key to the browser session and may be blocked by provider CORS rules. For public/multi-user use, add a secured backend and never place server secrets in frontend code.
